# NeuroDrive Python bridge dependencies.
#
# The bridge deliberately runs on the standard library alone in mock and
# replay mode -- you can clone the repo and run the whole pipeline, tests
# included, with nothing installed. pyserial is needed only to talk to real
# hardware.
#
#     pip install -r requirements.txt
#
# or run ../setup.ps1 (Windows) / ../setup.sh (macOS, Linux).

# Bluetooth serial link to the MindWave Mobile 2, and the USB serial
# fallback to the ESP32. Imported lazily, so its absence is only an error
# if you actually select a serial source or transport.
pyserial>=3.5

# Test runner. The suite also runs under `python -m unittest`, so this is
# convenience rather than a hard requirement.
pytest>=7.0

# Webcam gesture control (vision.py) needs two more packages. They are left
# out of this file on purpose: vision.py imports them lazily inside its own
# thread, so the bridge runs on a machine that has neither, as long as
# control.turn_source stays on "blink". Install them only on the laptop that
# will actually run the camera:
#
#     pip install mediapipe opencv-python
#
# The pose model is not a pip package. See vision.README.md for the one-line
# download into python_bridge/models/.
